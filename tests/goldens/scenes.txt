# Golden regression scenes (scripts/regress.sh). One per line:
#   name | image|audio | ENV=VALUE ... | skyward arguments | comparison options
# Images: headless --shot at 960x540 with live weather / time off and a fixed
# METAR, so only code changes move the pixels (and the tile cache: run from the
# repository root with cache/ populated). Audio: --audio-render, bit-exact
# today; the tolerance absorbs harmless DSP changes.
# Airport detail runs with SKYWARD_NO_OVERPASS=1 and SKYWARD_NO_APTDAT=1 (map tiles + procedural
# layout only: Overpass answers and the apt.dat import depend on the cache and the servers).
# Flight scenes run with SKYWARD_NO_VFX=1 so effects work (src/vfx) does not
# churn them; they still show the aircraft (aircraft*.wgsl / models.rs changes
# move chase_day, cockpit_*, night_city, rain_low_cloud, landmarks_city).
# terrain_alps / landmarks_city cover the DEM terrain + alpine shading and the
# procedural landmarks (St Paul's, the City towers).
# Land cover / canopy height (src/landcover/, Track LC) is on only in
# terrain_alps (WorldCover forest ground on the slopes, canopy-sized trees);
# its first run fetches some 20–30 MB into cache/landcover/, later runs read the
# cache. Every other image scene runs with SKYWARD_NO_LANDCOVER=1.
# Copernicus DEM GLO-30 (src/dem/, Track DEM) is likewise on only in
# terrain_alps (sharper slopes and ridges); its first run fetches ~40 MB into
# cache/copdem/. Every other image scene runs with SKYWARD_NO_COPDEM=1 SKYWARD_NO_MAPTERHORN=1.
# Mapterhorn terrain tiles (src/dem/mapterhorn.rs, Track MT; the elevation
# base, replacing Terrain Tiles + GLO-30 + LIDAR where it serves a tile) are on
# only in terrain_alps, the real-data scene (BEV 1 m ALS DTM around Innsbruck;
# its first run fetches ~5 MB into cache/mapterhorn/). Every other scene, the
# audio ones included, runs with SKYWARD_NO_MAPTERHORN=1 and keeps Terrain Tiles.
# The Environment Agency LIDAR DTM (src/dem/lidar.rs, Track LI; England only)
# is off in every image scene (SKYWARD_NO_LIDAR=1): it depends on the cache
# and the service, and terrain_alps is outside England anyway.
# Overture buildings (src/overture/, Track OV) are off in every image scene
# (SKYWARD_NO_OVERTURE=1): they depend on the cache and the current release.
# (SKYWARD_NO_SATTINT=1): EOX / GIBS imagery depends on the cache and the servers.
# The satellite tint (src/sattint/, Track SAT) is off in every image scene
# Far-field night lights (NASA Black Marble, lights/nightlights.rs, Track NL)
# are off in every image scene (SKYWARD_NO_NIGHTLIGHTS=1): they need a
# download, and night_city / cockpit_dusk would change with them.
# Bathymetry (src/bathy/, Track BY) is off in every image scene
# (SKYWARD_NO_BATHY=1): its depth tiles come from the network.
